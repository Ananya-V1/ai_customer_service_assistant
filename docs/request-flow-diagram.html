Request flow

Two journeys through the same four pieces

Every request in this app is one of two sequences below, moving between the same four actors: the Angular frontend, the Django backend, Ollama, and Postgres.

Frontend — Angular chat & upload UI
Backend — Django + DRF views & services
Ollama — local embedding & chat model
Postgres — rows + pgvector search
